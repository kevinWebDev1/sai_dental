## 🛠️ Tech Stack & Key Features
- **Framework:** Next.js 16 (App Router, Turbopack)
- **UI Library:** React 19 + Tailwind CSS v4
- **Icons:** Lucide React & React Icons (100% Vector SVGs, zero raw emojis)
- **Architecture:** Spider Web Architecture (Tier 1 High-Converting Healthcare Showcase)
- **Features:**
  - 100vh Perfectly Fitted Dynamic Hero with Transparent & Sticky Frosted Nav
  - Before/After Interactive Clinical Transformation Showcase (4 Cases with Stage-by-Stage Views)
  - 3:4 Mobile-Optimized Treatment & Technology Cards
  - Virtual Clinic Tour Carousel
  - Instant WhatsApp Appointment Drawer with Specialty & Timing Selectors
  - Dual Branch Location Switcher & Interactive Google Maps
  - Strict Anti-Slop Professional Aesthetics & Full GEO (Generative Engine Optimization) Structured Data
